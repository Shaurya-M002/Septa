Septa for Mac
=============

1. Unzip this folder.
2. Right-click "Install Septa.command" → Open (Gatekeeper may warn once).
3. Quit Hex.app when the installer finishes.

That clones https://github.com/Shaurya-M002/Septa into ~/Septa, starts the
local cleaner, and builds Septa.app if Xcode is installed.

Apple Silicon only. First run downloads a ~424 MB model.
