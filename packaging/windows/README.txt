Septa for Windows
=================

This is the same cleaner the Mac app uses (Qwen3-0.6B GGUF, POST /v1/clean).
Hex's dictation hotkey is macOS-only, so on Windows you paste or type into the
local page.

1. Unzip this folder.
2. Double-click "Install Septa.bat"  (needs Python 3.10+).
3. First run downloads the 424 MB model and llama.cpp.
4. Browser opens http://127.0.0.1:8742

Later, use "Start Septa.bat".

Nothing is sent to the cloud.
